## About Me

I am a Mechatronics Engineer with an MSc in Biomedical Engineering focused on the design of systems that connect **modeling, control, software and real-world implementation**.

My work includes control systems, biomedical devices, embedded systems, home automation, engineering software, simulation tools and technical education. I am particularly interested in projects where software interacts with a physical system and must be validated in practice.
