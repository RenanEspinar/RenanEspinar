## About

I am a Mechatronics Engineer with an MSc in Biomedical Engineering working at the intersection of **physical systems, control, software and applied research**.

I build engineering tools that move from theory to implementation: control-system models, biomedical simulations, embedded systems, home-automation infrastructure, Android applications and open-source integrations.

My repositories are primarily focused on solving concrete engineering problems and documenting the complete path from architecture and modeling to deployment and validation.

## Engineering Approach

I am particularly interested in projects where software interacts with a real physical system:

**model → simulate → implement → measure → validate → improve**

That includes control algorithms running on embedded hardware, biomedical systems interacting with sensors and actuators, automation infrastructure connected to real devices, and engineering software designed to make complex systems easier to understand or operate.
